# Book Catalog API Testing

## Overview

API testing project created using Postman for a Book Catalog REST API.

## Tools & Technologies

- Postman
- JavaScript
- REST APIs
- JWT Authentication
- MongoDB
- Git & GitHub

## Testing Covered

### User APIs
- User Registration
- User Login
- Input validation
- Duplicate user validation
- Invalid credentials
- Missing fields

### Book APIs
- Get all books
- Get book by ID
- Create book
- Update book
- Delete book

### Negative Testing
- Missing fields
- Invalid input
- Invalid book ID
- Non-existent book
- Duplicate book
- Missing JWT token
- Invalid JWT token
- Authentication/authorization failures

## Assertions

Postman scripts validate:

- HTTP status codes
- Response body
- Response fields
- Error messages
- Content-Type
- Response time
- Authentication responses

## Test Execution

The Postman collection can be imported and executed using the Postman Collection Runner.
